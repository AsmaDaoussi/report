% ---- 1.1 HOST ORGANIZATION ----
\section{Host Organization: Inherited Games Studio}

Inherited Games Studio is a game development company specializing in the creation of
educational and entertaining games. By leveraging immersive technologies such as virtual
reality (VR) and augmented reality (AR), the studio enhances user engagement and learning
experiences. Additionally, the integration of artificial intelligence (AI) allows for the
personalization of content, ensuring dynamic and interactive gameplay.

\subsection*{A. Mission}

The mission of Inherited Games Studio is to develop innovative and immersive games
that blend education and entertainment. Through the use of cutting-edge technology,
the company aims to offer users enriching, interactive, and engaging experiences that
enhance learning while maintaining a high level of fun.

\subsection*{B. Methodology}

To achieve its objectives, Inherited Games Studio follows a structured development approach that includes:

\begin{itemize}
  \item \textbf{Immersive Technologies:} Using VR and AR to create realistic and engaging environments.
  \item \textbf{AI-Driven Personalization:} Adapting gameplay and learning paths based on user interactions to enhance engagement and retention.
  \item \textbf{Multiplayer and Gamification:} Encourage social interaction and competition through multiplayer experiences and game-based incentives.
  \item \textbf{Continuous Optimization:} Analyze user feedback and performance metrics to refine and improve game mechanics.
  \item \textbf{Educational and Entertaining Design:} Ensure a balance between learning and enjoyment to maximize the impact of each game. By combining technology, creativity, and user-centered design, Inherited Games Studio continues to push the boundaries of immersive and interactive learning experiences.
\end{itemize}

% ---- 1.2 PROBLEM STATEMENT ----
\section{Problem Statement}

Before this project, IGS faced several critical operational pain points:

\begin{itemize}
  \item \textbf{No centralized asset repository:} Assets were scattered across local drives with no unified catalog or search.
  \item \textbf{No monetization platform:} IGS had no mechanism to sell surplus assets externally.
  \item \textbf{No role-based access control:} All internal users shared similar access levels, creating security concerns.
  \item \textbf{Fragmented workflows:} Collaboration relied on disconnected tools with no unified project management.
  \item \textbf{Dependency on foreign platforms:} International platforms (Unity Asset Store, Sketchfab, Fab) imposed dollar-denominated fees and no customization.
\end{itemize}

% ---- 1.4 PROPOSED SOLUTION ----
\section{Proposed Solution}

The proposed solution is a full-stack web platform composed of two interconnected applications:

\begin{enumerate}
  \item \textbf{IGS Marketplace (port 5173):} The public-facing marketplace where sellers list assets, buyers purchase and download content, and administrators moderate the catalog. It includes a 3D interactive viewer, Stripe checkout, a subscription system, and an AI chatbot assistant.
  \item \textbf{IGS Workspace (port 5174):} A private internal dashboard exclusively for IGS employees and interns, featuring team management, task tracking, project ERP modules, and a real-time direct messaging system.
\end{enumerate}

Both applications share the same backend API (Express.js on port 3001), the same PostgreSQL database, and the same authentication system (Firebase Auth + JWT), enabling seamless Single Sign-On between the two apps.

Nour Ltaief) naturally assumes the Product Owner role, the academic supervisor (Mr. Sami Ben Amor) assumes the Scrum Master role, and sprint reviews align with mandatory internship progress meetings.
