\subsection{AI Recommendation Engine}

The recommendation system uses a \textbf{two-stage pipeline} requiring no external AI API. A dedicated \texttt{user\_events} table records every interaction with weighted signals (Purchase: 10, Like: 5, Download: 3, View: 1).

\textbf{Stage 1 — Content-based scoring:} Each candidate asset is scored against the user's interest profile using four signals: Jaccard tag similarity (0--5 pts), category weight (0--3 pts), keyword overlap (0--2 pts), and a logarithmic popularity boost ($\leq$1.5 pts). Already-interacted assets are excluded.

\textbf{Stage 2 — Diversity-aware reranking:} The top-12 candidates are reordered with a category-diversity constraint (maximum 2 per category) to prevent homogeneous results. The final 8 recommendations include human-readable explanations generated deterministically from the profile match signals.

For users with no history (cold start), trending assets from the last 30 days are returned; unauthenticated visitors receive top-rated assets.

\subsection{IGS Marketplace Bot}

The floating chatbot widget is available on every page and uses the same three-layer architecture from Sprint 6: intent classification → live database tool use (for \texttt{product\_search} intent, the bot queries the PostgreSQL catalog and injects the top-5 results) → Mistral-7B-Instruct LLM generation (or rule-based fallback). The system prompt injects platform knowledge, the user's role, and the current page context for contextually relevant responses.
