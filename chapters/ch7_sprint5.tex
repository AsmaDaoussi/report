\section{Sprint 5: Internal Collaboration Platform}

\subsection*{Introduction}
Sprint 5 introduces the \textbf{IGS Workspace}, a companion internal web application designed exclusively for IGS employees and interns. It provides a ClickUp-inspired dashboard with team management, task tracking, project ERP, and a real-time chat system powered by Socket.io. Both applications share the same backend API and JWT, enabling seamless Single Sign-On.

\subsection{Analysis and Design}

\subsubsection{IGS Workspace Architecture}

The workspace is a separate React + Vite application (port 5174) that reads the shared JWT from \texttt{localStorage}, communicates with the same Express backend on port 3001, and enforces an internal-user guard at the layout level. Any unauthenticated or external user is immediately redirected.

\subsubsection{Real-Time Chat Architecture}

\begin{figure}[H]
\centering
\resizebox{0.9\textwidth}{!}{\input{diagrams/arch_chat.tex}}
\caption{Real-Time Chat Architecture with Socket.io}
\label{fig:sprint5_chat}
\end{figure}

The chat system uses Socket.io rooms: each channel maps to a room named \texttt{channel:\{id\}}; each DM pair shares a deterministic room \texttt{dm:\{userId1\}:\{userId2\}}. When a message is sent, the server persists it to PostgreSQL and broadcasts it to all room members in real time.

\subsubsection{Database Schema}

Sprint 5 adds six new entity groups: \texttt{workspace\_tasks}, \texttt{projects} and \texttt{project\_members}, \texttt{chat\_channels} and \texttt{channel\_members}, \texttt{chat\_messages} with \texttt{message\_reactions}, \texttt{direct\_messages}, and \texttt{company\_positions} with \texttt{team\_supervisors}.

\subsection{Sprint Review --- Deliverables}

\begin{itemize}
  \item IGS Workspace application (React + Vite, port 5174) with dark sidebar and topbar layout.
  \item Role-based sidebar navigation adapting to the authenticated user's internal role.
  \item Team directory with position management and supervisor assignment.
  \item Task management with priority, Kanban status flow, assignee, and due date.
  \item Project management with milestone tracking and team assignment.
  \item Real-time chat: channels, direct messages, emoji reactions, and read receipts.
  \item Seamless Single Sign-On between Marketplace and Workspace via shared JWT.
\end{itemize}
