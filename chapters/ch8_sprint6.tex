\section{Sprint 6: Artificial Intelligence Integration}

\subsection*{Introduction}
Sprint 6 integrates Machine Learning and AI capabilities into the platform. Two custom models are trained on domain-specific marketplace data: an intent classifier and a sentiment analyser. These are augmented by \textbf{Mistral-7B-Instruct}, an open-source large language model accessed via the HuggingFace Inference API, powering the marketplace assistant chatbot.

\subsection{AI System Architecture}

The AI integration follows a multi-layer architecture:

\begin{itemize}
  \item \textbf{Layer 1 — Trained ML Models (Python/scikit-learn):} Two models trained offline on domain-specific datasets and persisted as \texttt{.pkl} files, invoked at runtime via Python subprocess from Node.js.
  \item \textbf{Layer 2 — Open-Source LLM (Mistral-7B-Instruct):} The conversational chatbot uses Mistral-7B-Instruct-v0.3 via the HuggingFace Inference API (free tier). No proprietary API key required.
  \item \textbf{Layer 3 — Rule-Based Fallback:} If the LLM API is unavailable, an intent-keyed knowledge base covers all 12 identified intent categories.
\end{itemize}

The intent classifier (TF-IDF + LinearSVC) achieved a test set accuracy of \textbf{65.12\%} and macro F1-score of \textbf{0.668} across 12 classes, with perfect scores on \textit{greeting} and \textit{product\_search}. The sentiment model achieves 50\% accuracy on the small local dataset; in production it primarily leverages the DistilBERT-SST2 model via HuggingFace API, which exceeds 91\% accuracy on sentiment benchmarks.

\subsection{AI Review Analysis}

When a seller triggers the review analysis action, the pipeline fetches all reviews for the asset, classifies each via DistilBERT (with local sklearn fallback), then generates an aggregated summary covering: overall sentiment distribution, key strengths extracted from positive reviews, suggested improvements from negative reviews, and an actionable recommendation. Reviews rated 1--2 stars are also automatically run through the pipeline at submission time — if classified as \texttt{negative}, the \texttt{flagged\_for\_moderation} flag is set, creating an automated moderation queue.
